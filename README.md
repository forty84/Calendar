# Smart Calendar

**Smart Calendar** — это десктопное приложение для управления временем, разработанное на C++, с использованием графического фреймворка Qt. Приложение объединяет классический функционал планировщика с ежедневными прогнозами погоды и персональным гороскопом.

## Возможности (Features)
- **Визуальный календарь:** Удобный графический интерфейс для навигации по месяцам и неделям.
- **Управление событиями:** Создание, редактирование и удаление встреч, задач и напоминаний.
- **Интеграция погоды:** Автоматическое отображение погодных условий на выбранный день.
- **Гороскоп:** Просмотр ежедневного астрологического прогноза.

## Технологический стек
- **Язык программирования:** C++ (стандарт C++17/20).
- **GUI Фреймворк:** Qt (Qt Widgets / Qt Quick).
- **Архитектура ядра:** Построена на принципах ООП (наследование, полиморфизм) с активным использованием шаблонов и контейнеров STL для бизнес-логики.
- **Тестирование:** Unit-тестирование базовых компонентов.
